# Logo

`braian-mascot-512.png` is the BrAIan brain mascot at 512 × 512 with a transparent background: the largest version that exists. In `braian-codebase` the same file is the desktop app icon (`apps/desktop/assets/icon.png`), the Icon Composer layer (`apps/desktop/assets/BrAIan.icon/Assets/mascot.png`) and the PWA icon (`apps/web-app/public/brain-mascot-512.png`); the 192, 128 and 64 px icons are scaled down from it.

There is no vector source. At 1080p the mascot can fill up to about half the frame height without being scaled up; a 4K export, or a larger mascot, needs a new master (a redraw or an upscale saved here at a new size).
